The function returns human-readable sizes using binary units (1024-based), one decimal place for values ≥ 1 KB:

| Input | Output |
|-------|--------|
| 0 | `0 B` |
| 1536 | `1.5 KB` |
| 1048576 | `1.0 MB` |
| 1572864 | `1.5 MB` |

It handles each unit (B, KB, MB, GB, TB, PB) and falls back to the last unit for very large values. The existing `clamp` function is untouched.
