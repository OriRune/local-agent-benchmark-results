Now I can calculate the total sleep time. Looking at the code:

- `MAX_RETRIES = 3` means the loop runs for `attempt` values: 0, 1, 2 (3 attempts total)
- On each failed attempt, it sleeps for `2 ** attempt` seconds
  - Attempt 0: `2 ** 0 = 1` second
  - Attempt 1: `2 ** 1 = 2` seconds
  - Attempt 2: `2 ** 2 = 4` seconds

Total sleep time = 1 + 2 + 4 = **7 seconds**

Note: The code sleeps after each failed attempt, and after the 3rd failed attempt (attempt index 2), it raises the error without sleeping again. So there are 3 sleep calls totaling 7 seconds.
