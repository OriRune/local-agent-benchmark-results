```python
def format_bytes(n):
    """Format a number of bytes as a human-readable size, e.g. '1.5 KB'."""
    units = ["B", "KB", "MB", "GB", "TB", "PB"]
    size = float(n)
    for unit in units:
        if size < 1024:
            if unit == "B":
                return f"{int(size)} B"
            return f"{size:.1f} {unit}"
        size /= 1024
    return f"{size:.1f} EB"
```

Behavior: `format_bytes(1536)` → `'1.5 KB'`, `format_bytes(0)` → `'0 B'`, `format_bytes(1048576)` → `'1.0 MB'`, values ≥ 1 PB fall back to `'EB'`.
