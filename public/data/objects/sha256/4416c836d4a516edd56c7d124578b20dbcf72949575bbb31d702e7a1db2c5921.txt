```python
# app/units.py
UNITS = {"B": 1, "KB": 1000, "MB": 1024 ** 2, "GB": 1024 ** 3}
```

The test expects:
- `parse_size("1.5 KB") == 1536` (which is $1.5 \times 1024$)
- `parse_size("2 MB") == 2 * 1024 * 1024`

Because `KB` is currently `1000`, `parse_size("1.5 KB")` returns `1500` instead of `1536`.

To fix this, the `KB` value in `app/units.py` should be changed from `1000` to `1024`.
