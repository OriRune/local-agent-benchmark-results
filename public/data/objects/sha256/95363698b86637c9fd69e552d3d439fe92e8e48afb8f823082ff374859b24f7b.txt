# tinydl

A simple command-line tool to download content from a URL.

## Usage

```bash
tinydl [OPTIONS] <url>
```

## Command Line Options

| Option | Description |
| ------- | ----------- |
| `url` | what to download |
| `-o`, `--output` | file to write (default: stdout) |
| `-q`, `--quiet` | no progress output |

## Example

```bash
tinydl https://example.com/file.zip -o file.zip
```
