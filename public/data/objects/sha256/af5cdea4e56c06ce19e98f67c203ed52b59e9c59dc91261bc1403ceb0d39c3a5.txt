## Setting Up the Grid

Let me index cells as (row, col):

```
       col:0  1  2  3  4  5
row 0:      X  O  X  O  O  O
row 1:      O  O  O  O  O  #
row 2:      O  O  X  O  O  O
row 3:      O  O  O  *  O  X
row 4:      X  X  O  X  O  O
row 5:      X  X  O  O  X  O
```

- **Start:** (3,3)
- **Destination:** (1,5)

## BFS Search

The Manhattan distance from (3,3) to (1,5) is |3−1| + |5−3| = **4**, which is the theoretical minimum.

Tracing a path of length 4:

| Step | Move | Cell | Type |
|------|------|------|------|
| Start | — | (3,3) | * |
| 1 | up | (2,3) | O ✓ |
| 2 | up | (1,3) | O ✓ |
| 3 | right | (1,4) | O ✓ |
| 4 | right | (1,5) | # ✓ |

This path reaches the destination in exactly 4 steps, matching the Manhattan distance — so it is optimal.
