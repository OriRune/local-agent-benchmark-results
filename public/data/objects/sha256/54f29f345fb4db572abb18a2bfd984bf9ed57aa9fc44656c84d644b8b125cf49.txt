I found the fetch tool implementation in `app/net.py`:

```python
def fetch(url, get):
    # TODO: log each failed attempt
    for attempt in range(MAX_RETRIES):
        try:
            return get(url, timeout=TIMEOUT_S)
        except OSError:
            time.sleep(2 ** attempt)
    raise RuntimeError(f"giving up on {url}")
```

And in `app/config.py`:
```python
MAX_RETRIES = 3
```

So if every attempt fails, it retries 3 times (attempts 0, 1, 2) and sleeps for 1 + 2 + 4 = 7 seconds before giving up.
