Now I can calculate the total sleep time. Looking at the code in `app/net.py`:

- `MAX_RETRIES = 3` means the loop runs 3 times (attempt = 0, 1, 2)
- On each failed attempt, it sleeps for `2 ** attempt` seconds
- Attempt 0: sleeps 2⁰ = 1 second
- Attempt 1: sleeps 2¹ = 2 seconds
- Attempt 2: sleeps 2² = 4 seconds

**Total sleep time: 1 + 2 + 4 = 7 seconds**

When all fetch attempts fail, the code spends **7 seconds** sleeping in total before giving up.
