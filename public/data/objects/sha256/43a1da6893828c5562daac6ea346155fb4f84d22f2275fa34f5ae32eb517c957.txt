The `fetch` function in `app/net.py` retries up to `MAX_RETRIES` (which is set to 3 in `app/config.py`). After each failed attempt it sleeps for `2 ** attempt` seconds. If all attempts fail, the total sleep time is:

- Attempt 0: `2**0 = 1` second
- Attempt 1: `2**1 = 2` seconds
- Attempt 2: `2**2 = 4` seconds

Total = `1 + 2 + 4 = 7` seconds.

**Answer: 7 seconds.**
