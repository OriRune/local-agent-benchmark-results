Created `README.md` for the `tinydl` downloader. It documents every CLI option from `app/cli.py` with its exact help text:

| Option | Help text |
| --- | --- |
| `url` | what to download |
| `-o`, `--output` | file to write (default: stdout) |
| `-q`, `--quiet` | no progress output |
| `-h`, `--help` | show this help message and exit |

The README also includes a short project description, the usage line, and two example invocations.
