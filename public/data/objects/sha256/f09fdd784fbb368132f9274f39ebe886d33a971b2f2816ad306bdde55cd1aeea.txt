Looking at the code in `app/net.py`:

```python
def fetch(url, get):
    for attempt in range(MAX_RETRIES):
        try:
            return get(url, timeout=TIMEOUT_S)
        except OSError:
            time.sleep(2 ** attempt)
    raise RuntimeError(f"giving up on {url}")
```

And from `app/config.py`:
- `MAX_RETRIES = 3`

The loop runs for `attempt = 0, 1, 2` (3 iterations). On each failed attempt, it sleeps for `2 ** attempt` seconds:
- Attempt 0: `2^0 = 1` second
- Attempt 1: `2^1 = 2` seconds  
- Attempt 2: `2^2 = 4` seconds

**Total sleep time: 1 + 2 + 4 = 7 seconds**

If every attempt fails, the function spends 7 seconds sleeping before giving up.
