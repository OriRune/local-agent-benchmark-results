The test `tests/test_units.py` fails because of a discrepancy in the `UNITS` dictionary in `app/units.py`.

`"Sizes use 1024-based units: 1 KB = 1024 bytes."`

However, the `UNITS` dictionary is defined as:
`UNITS = {"B": 1, "KB": 1000, "MB": 1024 ** 2, "GB": 1024 ** 3}`

In this dictionary, `"KB"` is set to `1000`, which contradicts both the docstring and the test case `assert parse_size("1.5 KB") == 1536` (since $1.5 \times 1024 = 1536$).

To fix the code, the value for `"KB"` in `app/units.py` should be changed from `1000` to `1024`.
