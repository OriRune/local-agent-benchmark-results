I have created a `README.md` file that lists all the command-line options for the `tinydl` CLI, along with their respective help texts as defined in `app/cli.py`.

```markdown
# tinydl

A simple command-line tool for downloading files.

## Command Line Options

- `url`: what to download
- `-o`, `--output`: file to write (default: stdout)
- `-q`, `--quiet`: no progress output
```
