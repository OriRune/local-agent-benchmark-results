The fix is correct.

**Root cause:** The `UNITS` dictionary in `app/units.py` defined `"KB": 1000` (decimal/base-1000), which contradicted the module's documented convention that "Sizes use 1024-based units: 1 KB = 1024 bytes." This caused `parse_size("1.5 KB")` to return `1500` instead of the expected `1536`.

**Fix:** Changed `"KB": 1000` to `"KB": 1024` so it aligns with the 1024-based convention used for the other units and the docstring.
