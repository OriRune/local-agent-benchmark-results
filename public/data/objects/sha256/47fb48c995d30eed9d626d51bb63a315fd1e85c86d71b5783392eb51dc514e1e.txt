The bug was in `app/units.py`. The `UNITS` dictionary had `"KB": 1000` instead of `"KB": 1024`. This caused `parse_size("1.5 KB")` to return `1500` instead of the expected `1536`.

The fix changes `"KB": 1000` to `"KB": 1024`, which aligns with the comment ("Sizes use 1024-based units") and the test assertions.
