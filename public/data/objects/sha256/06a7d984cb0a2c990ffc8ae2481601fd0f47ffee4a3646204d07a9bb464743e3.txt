# tinydl

A simple command line downloader.

## Usage

```bash
tinydl [URL] [OPTIONS]
```

## Options

| Argument | Short | Long | Help Text |
| --- | --- | --- | --- |
| `url` | | | what to download |
| `-o` | `--output` | | file to write (default: stdout) |
| `-q` | `--quiet` | | no progress output |
```
