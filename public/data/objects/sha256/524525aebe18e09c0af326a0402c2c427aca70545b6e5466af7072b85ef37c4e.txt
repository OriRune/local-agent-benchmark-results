Fixed. The issue was that `KB` was defined as `1000` in the `UNITS` dictionary, but the docstring says the module uses 1024-based units (1 KB = 1024 bytes). The test expects `parse_size("1.5 KB")` to return `1536` (which is `1.5 * 1024`), but with `KB = 1000`, it would return `1500`.

I changed `KB` from `1000` to `1024` to match the documented behavior and the test expectations.
