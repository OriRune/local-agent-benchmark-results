# tinydl

A simple command-line tool to download files from the internet.

## Usage

```bash
tinydl [OPTIONS] URL
```

## Arguments

* `URL`: what to download

## Options

* `-o`, `--output`: file to write (default: stdout)
* `-q`, `--quiet`: no progress output

## Example

```bash
tinydl -o my_file.zip http://example.com/my_file.zip
```
