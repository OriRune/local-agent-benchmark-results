## BFS Search

The Manhattan distance is |3−1| + |5−3| = **4**, so the shortest possible path is 4 moves.

Tracing from start (3,3):
- **up** → (2,3) = O ✓
- **up** → (1,3) = O ✓
- **right** → (1,4) = O ✓
- **right** → (1,5) = # ✓

This reaches the destination in exactly 4 moves, which equals the theoretical minimum.
