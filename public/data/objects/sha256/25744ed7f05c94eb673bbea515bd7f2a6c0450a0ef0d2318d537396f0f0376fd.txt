Done! I've added the `format_bytes(n)` function to `app/util.py` that returns human-readable sizes like '1.5 KB'. The function:
- Returns bytes as-is for values less than 1024
- Returns KB (kilobytes) with one decimal place for values up to 1 MB
- Returns MB (megabytes) with one decimal place for values up to 1 GB
- Returns GB (gigabytes) with one decimal place for larger values
