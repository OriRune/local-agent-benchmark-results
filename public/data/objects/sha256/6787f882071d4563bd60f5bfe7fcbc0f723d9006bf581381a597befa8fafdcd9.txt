Based on the code in `app/net.py` and `app/config.py`, the `fetch` function will spend a total of **7 seconds** sleeping if every attempt fails.

2.  **`app/net.py`** implements the retry logic:
    ```python
    for attempt in range(MAX_RETRIES):
        try:
            return get(url, timeout=TIMEOUT_S)
        except OSError:
            time.sleep(2 ** attempt)
    ```
3.  If every attempt fails with an `OSError`, the sleep durations are:
    *   **Attempt 0:** `2 ** 0 = 1` second
    *   **Attempt 1:** `2 ** 1 = 2` seconds
    *   **Attempt 2:** `2 ** 2 = 4` seconds
