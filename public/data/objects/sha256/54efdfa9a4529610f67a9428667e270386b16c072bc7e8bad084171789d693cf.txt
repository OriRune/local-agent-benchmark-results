To determine the total sleep time if every attempt in `fetch` fails, we look at the logic in `app/net.py`:

```python
def fetch(url, get):
    # TODO: log each failed attempt
    for attempt in range(MAX_RETRIES):
        try:
            return get(url, timeout=TIMEOUT_S)
        except OSError:
            time.sleep(2 ** attempt)
    raise RuntimeError(f"giving up on {url}")
```

From `app/config.py`, we have:
- `MAX_RETRIES = 3`

The loop runs for `attempt` values `0, 1, 2`.
The sleep time for each attempt is `2 ** attempt`:
1.  **Attempt 0**: `2 ** 0` = 1 second
2.  **Attempt 1**: `2 ** 1` = 2 seconds
3.  **Attempt 2**: `2 ** 2` = 4 seconds

Total sleep time = $1 + 2 + 4 = 7$ seconds.
