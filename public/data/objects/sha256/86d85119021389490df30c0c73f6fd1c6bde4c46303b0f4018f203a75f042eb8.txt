## Summary

**Root cause:** In `app/units.py`, the `UNITS` dictionary defined `"KB": 1000`, but the module explicitly documents that sizes use 1024-based units ("1 KB = 1024 bytes"). This inconsistency caused `parse_size("1.5 KB")` to return `1500` (1.5 × 1000) instead of the expected `1536` (1.5 × 1024). The other units (MB, GB) correctly used 1024-based multipliers, so only KB was wrong.

**Fix:** Changed `"KB": 1000` to `"KB": 1024` in `app/units.py`.

The test now passes for all three assertions:
- `parse_size("512 B")` → 512 ✓
- `parse_size("1.5 KB")` → 1536 ✓
- `parse_size("2 MB")` → 2097152 ✓
