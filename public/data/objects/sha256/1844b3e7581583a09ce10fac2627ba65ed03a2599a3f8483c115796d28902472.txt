Now I can calculate the total sleep time:

From the code in `app/net.py`:
- `MAX_RETRIES = 3` (from `app/config.py`)
- On each failed attempt, it sleeps for `2 ** attempt` seconds
- The loop runs for `attempt` values: 0, 1, 2 (3 attempts total)

Sleep times per attempt:
- Attempt 0: `2^0 = 1` second
- Attempt 1: `2^1 = 2` seconds  
- Attempt 2: `2^2 = 4` seconds

**Total sleep time: 1 + 2 + 4 = 7 seconds**

When all fetch attempts fail, it spends **7 seconds** sleeping in total before giving up.
