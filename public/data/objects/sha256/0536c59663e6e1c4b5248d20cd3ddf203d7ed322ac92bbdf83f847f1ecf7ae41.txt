The new function handles various units (B, KB, MB, GB, TB, PB) and formats the output to one decimal place (e.g., '1.5 KB'), except for bytes which are shown as whole numbers.

```python
def format_bytes(n):
    for unit in ['B', 'KB', 'MB', 'GB', 'TB']:
        if n < 1024:
            return f"{n:.1f} {unit}" if unit != 'B' else f"{n} {unit}"
        n /= 1024
    return f"{n:.1f} PB"
```
