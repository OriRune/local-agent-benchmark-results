**Total sleep: 7 seconds.**

From `app/net.py`:

```python
for attempt in range(MAX_RETRIES):      # MAX_RETRIES = 3 → attempts 0, 1, 2
    try:
        return get(url, timeout=TIMEOUT_S)
    except OSError:
        time.sleep(2 ** attempt)
raise RuntimeError(...)
```

With `MAX_RETRIES = 3` (from `app/config.py`), every failing attempt sleeps `2 ** attempt`:

| attempt | sleep |
|---|---|
| 0 | 2⁰ = 1 s |
| 1 | 2¹ = 2 s |
| 2 | 2² = 4 s |

1 + 2 + 4 = **7 seconds** of sleeping before the `RuntimeError("giving up on ...")` is raised.

Note: the sleep happens even after the last (third) failed attempt, so the code sleeps 7 s and *then* gives up — if you'd rather not sleep pointlessly after the final failure, the sleep could be skipped when `attempt == MAX_RETRIES - 1`.
