Looking at the code in `app/net.py`:

```python
def fetch(url, get):
    for attempt in range(MAX_RETRIES):
        try:
            return get(url, timeout=TIMEOUT_S)
        except OSError:
            time.sleep(2 ** attempt)
    raise RuntimeError(f"giving up on {url}")
```

And from `app/config.py`:
- `MAX_RETRIES = 3`

The loop runs for `attempt` values: 0, 1, 2 (since `range(3)` produces 0, 1, 2).

When every attempt fails (each `get` raises `OSError`), the sleep times are:
- Attempt 0: 2^0 = 1 second
- Attempt 1: 2^1 = 2 seconds
- Attempt 2: 2^2 = 4 seconds

**Total sleep time = 1 + 2 + 4 = 7 seconds**

The code then gives up by raising `RuntimeError` after exhausting all retry attempts.
