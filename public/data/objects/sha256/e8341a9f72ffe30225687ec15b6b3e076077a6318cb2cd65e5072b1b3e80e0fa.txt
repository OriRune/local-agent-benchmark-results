The sandbox can't run Python in this session, but the fix is straightforward and verifiable by inspection.

**Why the test failed:** In `app/units.py`, the `UNITS` table defined `"KB": 1000`, but the module docstring and the test both assume 1024-based units (1 KB = 1024 bytes). So `parse_size("1.5 KB")` returned `1500` instead of `1536`.

**Fix:** Changed `UNITS = {"B": 1, "KB": 1000, ...}` to `UNITS = {"B": 1, "KB": 1024, ...}` in `app/units.py`. All three assertions now hold:
- `parse_size("512 B")` → 512 ✓
- `parse_size("1.5 KB")` → 1.5 × 1024 = 1536 ✓
- `parse_size("2 MB")` → 2 × 1024² ✓

The test file was left untouched.
