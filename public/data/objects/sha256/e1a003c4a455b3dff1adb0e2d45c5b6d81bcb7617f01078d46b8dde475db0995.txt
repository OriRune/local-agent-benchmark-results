Looking at the code in `app/net.py`, the fetch function uses exponential backoff sleeping:

```python
for attempt in range(MAX_RETRIES):
    try:
        return get(url, timeout=TIMEOUT_S)
    except OSError:
        time.sleep(2 ** attempt)
```

From `app/config.py`, `MAX_RETRIES = 3`, so the loop runs for `attempt` values 0, 1, and 2.

If every attempt fails, the sleep times are:
- Attempt 0: `2 ** 0 = 1` second
- Attempt 1: `2 ** 1 = 2` seconds  
- Attempt 2: `2 ** 2 = 4` seconds

**Total sleep time: 1 + 2 + 4 = 7 seconds**
