Now I can work out the total sleep time:

The code shows:
- `MAX_RETRIES = 3` (from config.py)
- The sleep happens in a loop: `for attempt in range(MAX_RETRIES)` which means attempt = 0, 1, 2
- Sleep is `time.sleep(2 ** attempt)`

So the sleep times are:
- attempt 0: 2^0 = 1 second
- attempt 1: 2^1 = 2 seconds  
- attempt 2: 2^2 = 4 seconds

Total sleep = 1 + 2 + 4 = **7 seconds**

The loop runs 3 times (for attempts 0, 1, 2), and if all 3 attempts fail, it will sleep 1 + 2 + 4 = 7 seconds before giving up.
