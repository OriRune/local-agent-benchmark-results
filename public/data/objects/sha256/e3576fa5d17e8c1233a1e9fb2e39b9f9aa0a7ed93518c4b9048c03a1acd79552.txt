I've successfully added the `format_bytes(n)` function to `app/util.py` and removed the TODO comment. The function:

- Returns bytes as-is for values less than 1024 (e.g., "512 B")
- Returns KB for values less than 1 MB (e.g., "1.5 KB")
- Returns MB for values less than 1 GB (e.g., "2.3 MB")
- Returns GB for larger values (e.g., "1.2 GB")

All values are formatted to one decimal place for readability.
