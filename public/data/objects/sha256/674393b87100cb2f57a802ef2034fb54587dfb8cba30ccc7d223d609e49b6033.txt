The README.md has been created at the project root. It documents all three CLI options from `app/cli.py`:

- **`url`** (positional) — "what to download"
- **`-o` / `--output`** — "file to write (default: stdout)"
- **`-q` / `--quiet`** — "no progress output"

It also includes a usage summary line and a few example invocations for context.
