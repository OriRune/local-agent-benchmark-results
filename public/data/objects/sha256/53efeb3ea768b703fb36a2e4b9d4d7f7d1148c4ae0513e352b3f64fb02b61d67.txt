The function iterates through size units (B, KB, MB, GB, TB, PB), dividing by 1024 until the value is below 1024, then formats it. For example, `format_bytes(1536)` returns `'1.5 KB'`, and whole byte counts like `format_bytes(512)` return `'512 B'`.

```python
def format_bytes(n):
    """Return a human-readable size string, e.g. '1.5 KB' for 1536 bytes."""
    unit = "B"
    for unit in ("B", "KB", "MB", "GB", "TB", "PB"):
        if n < 1024 or unit == "PB":
            if unit == "B":
                return f"{int(n)} {unit}"
            return f"{n:.1f} {unit}"
        n /= 1024
```
