Here's the calculation.

The loop runs `for attempt in range(MAX_RETRIES)` with `MAX_RETRIES = 3`, so `attempt` takes values 0, 1, 2. On every failed attempt it sleeps `2 ** attempt` seconds:

- attempt 0 → 2⁰ = 1 s
- attempt 1 → 2¹ = 2 s
- attempt 2 → 2² = 4 s

Total = 1 + 2 + 4 = **7 seconds**.

(The sleep happens only on the failed attempts inside the loop, and the loop runs exactly 3 times, so all three sleeps occur before it raises the "giving up" error.)
