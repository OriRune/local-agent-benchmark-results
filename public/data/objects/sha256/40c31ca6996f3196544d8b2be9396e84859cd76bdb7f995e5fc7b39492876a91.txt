I've created `README.md` documenting every command line option of the `tinydl` CLI.

The CLI's options all come from the single `build_parser()` function in `app/cli.py`, so I listed each one with its exact help text:

- **`url`** — *what to download* (positional)
- **`-o`, `--output`** — *file to write (default: stdout)*
- **`-q`, `--quiet`** — *no progress output*

Note: `config.py` defines settings like retries and timeout, but these are not exposed as CLI arguments, so they're correctly excluded from the options list. (I couldn't run `--help` to verify live output since the sandbox can't execute programs, so the help text is taken directly from the argparse definitions.)
