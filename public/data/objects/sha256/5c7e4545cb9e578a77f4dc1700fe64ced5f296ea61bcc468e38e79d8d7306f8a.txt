Fixed. 

**Root cause:** In `app/units.py`, the `KB` unit was mapped to `1000` (decimal) instead of `1024` (binary). This made `parse_size("1.5 KB")` return `1500` instead of the expected `1536`, failing the test. The module's own docstring states sizes are "1024-based units: 1 KB = 1024 bytes," so the `1000` value was inconsistent with the intended behavior.

**Fix:** Changed `KB` from `1000` to `1024`. All three test assertions now pass:
- `parse_size("512 B") == 512` ✓
- `parse_size("1.5 KB") == 1536` ✓
- `parse_size("2 MB") == 2 * 1024 * 1024` ✓
