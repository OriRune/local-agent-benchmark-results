Done. I created `README.md` listing every command line option of the `tinydl` CLI from `app/cli.py`:

- **`url`** — what to download (positional argument)
- **`-h`, `--help`** — show this help message and exit (the standard argparse help flag)
- **`-o`, `--output`** — file to write (default: stdout)
- **`-q`, `--quiet`** — no progress output

Each is shown with its exact help text in a table, plus the usage line.
