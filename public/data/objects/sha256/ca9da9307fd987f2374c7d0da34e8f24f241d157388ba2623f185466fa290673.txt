**Why the test failed:** In `app/units.py`, the `UNITS` table had `"KB": 1000`, but the module's own docstring and the test both say sizes are 1024-based (1 KB = 1024 bytes). So `parse_size("1.5 KB")` returned `1500` instead of `1536`.

**Fix:** Changed `"KB": 1000` to `"KB": 1024` in `app/units.py`. Now:
- `parse_size("512 B")` → 512 ✓
- `parse_size("1.5 KB")` → 1.5 × 1024 = 1536 ✓
- `parse_size("2 MB")` → 2 × 1024² = 2097152 ✓

The test file was left untouched.
