# tinydl - A Simple Command-Line Downloader

`tinydl` is a lightweight command-line tool for downloading content from a URL.

## CLI Usage

```sh
tinydl [options] <url>
```

## Command-Line Options

| Option          | Description                                                                 |
|-----------------|-----------------------------------------------------------------------------|
| `url`           | **Required**: The URL of the resource to download.                         |
| `-o, --output`  | Specify the file to write the downloaded content to (default: stdout).     |
| `-q, --quiet`   | Suppress progress output (no byte count displayed).                         |
```
