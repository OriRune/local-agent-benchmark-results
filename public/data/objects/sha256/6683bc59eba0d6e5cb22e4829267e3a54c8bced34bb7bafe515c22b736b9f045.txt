The README.md has been written. It documents the `tinydl` CLI with all three command-line options:

- **`URL`** (positional) — what to download
- **`-o` / `--output`** — file to write (default: stdout)
- **`-q` / `--quiet`** — no progress output

Each option is listed with its exact help text as defined in `app/cli.py`.
