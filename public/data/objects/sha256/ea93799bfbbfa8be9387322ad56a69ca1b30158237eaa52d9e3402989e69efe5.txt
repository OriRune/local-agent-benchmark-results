Working it out from the code:

**`fetch` (app/net.py):**
```python
for attempt in range(MAX_RETRIES):
    try:
        return get(url, timeout=TIMEOUT_S)
    except OSError:
        time.sleep(2 ** attempt)
raise RuntimeError(f"giving up on {url}")
```

**`MAX_RETRIES = 3`** (app/config.py), so `attempt` runs 0, 1, 2.

If every attempt fails, it sleeps after each one:
- attempt 0 → `2**0` = 1 s
- attempt 1 → `2**1` = 2 s
- attempt 2 → `2**2` = 4 s

Total: **1 + 2 + 4 = 7 seconds** before it raises `RuntimeError` and gives up.
