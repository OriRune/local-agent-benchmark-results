Now I can calculate the total sleep time. The `fetch` function in `app/net.py` has the following behavior:

1. **MAX_RETRIES = 3** (from `app/config.py`)
2. The loop runs for `attempt` values of 0, 1, 2 (3 attempts total)
3. Each failed attempt sleeps for `2 ** attempt` seconds:
   - Attempt 0: `2^0 = 1` second
   - Attempt 1: `2^1 = 2` seconds
   - Attempt 2: `2^2 = 4` seconds

**Total sleep time = 1 + 2 + 4 = 7 seconds**

So if every attempt fails, the function spends **7 seconds** sleeping in total before giving up.
