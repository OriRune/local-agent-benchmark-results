```python
for attempt in range(MAX_RETRIES):  # MAX_RETRIES = 3
    try:
        return get(url, timeout=TIMEOUT_S)
    except OSError:
        time.sleep(2 ** attempt)
```

`range(3)` gives `attempt` values 0, 1, 2 — so the loop runs 3 times, and on every failed attempt it sleeps `2 ** attempt` seconds:

- attempt 0 → sleep 2⁰ = 1s
- attempt 1 → sleep 2¹ = 2s
- attempt 2 → sleep 2² = 4s

Total = 1 + 2 + 4 = **7 seconds**.

(Note: if a fetch *succeeds* on an earlier attempt, it returns immediately and never sleeps — but if every attempt fails, it sleeps through all three before raising "giving up".)
