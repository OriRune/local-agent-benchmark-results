Based on the code in `app/net.py` and `app/config.py`:

1. **MAX_RETRIES = 3** (from config.py)
2. The fetch function loops through `range(MAX_RETRIES)`, which means attempts 0, 1, and 2
3. On each failed attempt, it sleeps for `2 ** attempt` seconds

The sleep times are:
- Attempt 0: 2^0 = **1 second**
- Attempt 1: 2^1 = **2 seconds**
- Attempt 2: 2^2 = **4 seconds**

**Total sleep time: 1 + 2 + 4 = 7 seconds**

The function will give up after all 3 attempts fail and raise a RuntimeError.
