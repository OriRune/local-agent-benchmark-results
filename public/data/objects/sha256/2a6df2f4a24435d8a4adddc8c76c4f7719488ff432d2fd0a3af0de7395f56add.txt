# Finding the Shortest Path

Let me set up coordinates (row, col) and parse the grid:

```
     0  1  2  3  4  5
  0: X  O  X  O  O  O
  1: O  O  O  O  O  #
  2: O  O  X  O  O  O
  3: O  O  O  *  O  X
  4: X  X  O  X  O  O
  5: X  X  O  O  X  O
```

**Start:** (3,3)  **Destination:** (1,5)

## BFS Exploration

- **(3,3)** — start
- **(3,4)** — right
- **(2,4)** — up
- **(1,4)** — up
- **(1,5)** — right → **destination!**

## Verification

| Step | Cell | Value | Move |
|------|------|-------|------|
| 0 | (3,3) | `*` | start |
| 1 | (3,4) | `O` | right |
| 2 | (2,4) | `O` | up |
| 3 | (1,4) | `O` | up |
| 4 | (1,5) | `#` | right |

The Manhattan distance is |3−1| + |3−5| = 4, and we achieved this minimum, so this is optimal.
