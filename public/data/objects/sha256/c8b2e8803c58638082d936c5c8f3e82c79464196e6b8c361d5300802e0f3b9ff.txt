# Tiny Downloader (tinydl)

A simple command-line tool to download files from the web.

## Usage

```bash
tinydl [OPTIONS] URL
```

## Command Line Options

| Option | Description |
|--------|-------------|
| `url` | What to download. |
| `-o, --output` | File to write (default: stdout). |
| `-q, --quiet` | No progress output. |
