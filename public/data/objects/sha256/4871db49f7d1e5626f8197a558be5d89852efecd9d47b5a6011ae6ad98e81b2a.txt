I have created a Python script named `system_info.py` in the current directory that displays the CPU and RAM usage.

You can run it using the following command:
```bash
python3 system_info.py
```

The script provides:
- CPU Usage percentage
- Memory Usage percentage
- Total Memory in GB
- Available Memory in GB

Here is the content of the script:
```python
import psutil

def get_system_info():
    cpu_usage = psutil.cpu_percent(interval=1)
    memory_info = psutil.virtual_memory()
    
    print(f"CPU Usage: {cpu_usage}%")
    print(f"Memory Usage: {memory_info.percent}%")
    print(f"Memory Total: {memory_info.total / (1024**3):.2f} GB")
    print(f"Memory Available: {memory_info.available / (1024**3):.2f} GB")

if __name__ == "__main__":
    get_system_info()
```
