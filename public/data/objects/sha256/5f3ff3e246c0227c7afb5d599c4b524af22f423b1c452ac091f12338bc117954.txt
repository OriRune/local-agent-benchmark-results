```python
def clamp(x, lo, hi):

def format_bytes(n):
    """Return a human-readable size such as '1.5 KB'."""
    value = float(n)
    for unit in ("B", "KB", "MB", "GB", "TB"):
        if abs(value) < 1024.0:
            return f"{value:.1f} {unit}" if unit != "B" else f"{int(value)} B"
        value /= 1024.0
    return f"{value:.1f} PB"
```

`format_bytes(n)` converts a byte count into a human-readable string, e.g. `1024` → `"1.0 KB"`, `1536` → `"1.5 KB"`, `1048576` → `"1.0 MB"`. The TODO comment is gone.
