Looking at the code in `app/net.py` and `app/config.py`:

The `fetch` function loops `range(MAX_RETRIES)` times, and if each attempt fails, it sleeps for `2 ** attempt` seconds before retrying.

From `app/config.py`, `MAX_RETRIES = 3`, so the loop runs for `attempt = 0, 1, 2`.

If every attempt fails, the total sleep time is:
- attempt 0: 2^0 = 1 second
- attempt 1: 2^1 = 2 seconds  
- attempt 2: 2^2 = 4 seconds

**Total: 7 seconds**
