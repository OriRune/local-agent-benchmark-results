The function converts a number of bytes into a human-readable string (e.g., `1.5 KB`, `500 B`, `1 MB`).

```python
def format_bytes(n):
    for unit in ['B', 'KB', 'MB', 'GB', 'TB']:
        if n < 1024:
            return f"{n:.1f} {unit}".replace(".0 ", " ")
        n /= 1024
    return f"{n:.1f} PB"
```
