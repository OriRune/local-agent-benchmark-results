Here's the work:

The loop runs `for attempt in range(MAX_RETRIES)` with `MAX_RETRIES = 3`, so `attempt` takes values **0, 1, 2** (three iterations). On each failed attempt it sleeps `2 ** attempt` seconds:

- attempt 0 → 2⁰ = 1 s
- attempt 1 → 2¹ = 2 s
- attempt 2 → 2² = 4 s

Total sleep = 1 + 2 + 4 = **7 seconds**.

(After the third failure the loop ends and it raises `RuntimeError("giving up on {url}")`.)
