Done. I added `format_bytes(n)` to `app/util.py` and removed the TODO comment about it.

The function walks through the units B, KB, MB, GB, TB, PB, EB, ZB, YB and returns a string like:
- `1536` → `'1.5 KB'`
- `1024` → `'1 KB'` (whole numbers drop the trailing `.0`)
- `1073741824` → `'1 GB'`
- `0` → `'0 B'`
