The test `tests/test_units.py` fails because there is a discrepancy between the docstring/test expectations and the actual implementation in `app/units.py`.

**Findings:**
1.  **The Test Expectation:** The test expects `parse_size("1.5 KB")` to equal `1536`. Since $1.5 \times 1024 = 1536$, the test assumes a binary prefix (1 KB = 1024 bytes).
2.  **The Implementation Bug:** In `app/units.py`, the `UNITS` dictionary defines `"KB"` as `1000`:
    ```python
    UNITS = {"B": 1, "KB": 1000, "MB": 1024 ** 2, "GB": 1024 ** 3}
    ```
    This causes `parse_size("1.5 KB")` to return `1500` instead of the expected `1536`.

**Fix:**
Change the value of `"KB"` in `app/units.py` from `1000` to `1024`.
