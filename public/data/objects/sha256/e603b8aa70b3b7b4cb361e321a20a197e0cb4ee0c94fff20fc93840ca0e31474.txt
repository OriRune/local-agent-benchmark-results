# Tiny Downloader CLI

A simple command line tool to download files from URLs.

## Command Line Options

| Option | Description |
|--------|-------------|
| `url` | The URL to download. |
| `-o, --output` | The file to write the downloaded data to. Default is stdout. |
| `-q, --quiet` | If set, no progress output is shown. |
