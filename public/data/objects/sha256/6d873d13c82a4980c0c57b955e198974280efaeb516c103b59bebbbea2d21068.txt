Done. I added `format_bytes(n)` to `app/util.py` and removed the TODO comment.

The function returns human-readable sizes using binary units (1024-based):
- `format_bytes(1536)` → `'1.5 KB'`
- `format_bytes(1024)` → `'1.0 KB'`
- `format_bytes(5)` → `'5 B'`
- `format_bytes(1024**3)` → `'1.0 GB'`

It handles the "B" unit as an integer and larger units with one decimal place, up to "PB".
