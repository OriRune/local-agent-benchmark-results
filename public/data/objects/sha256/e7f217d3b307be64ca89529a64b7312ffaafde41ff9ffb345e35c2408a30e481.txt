# Course Schedule - Cycle Detection

I need to determine if there's a cycle in the prerequisite graph. If there's no cycle, all courses can be completed.

**Building the graph** (edge from b_i → a_i, since b_i must come first):
- 3→5, 3→7, 2→4, 4→0, 1→6, 4→1, 2→7, 3→2

**Adjacency list:**
- 3: [5, 7, 2]
- 2: [4, 7]
- 4: [0, 1]
- 1: [6]

**Kahn's Topological Sort (in-degree based):**

| Step | In-degrees 0 | Process |
|------|-------------|---------|
| 1 | {3} | Remove 3→5, 3→7, 3→2 |
| 2 | {5, 2} | Remove 2→4, 2→7 |
| 3 | {4, 7} | Remove 4→0, 4→1 |
| 4 | {7, 0, 1} | Remove 1→6 |
| 5 | {6} | Done |

**Result:** All 8 nodes were processed (0,1,2,3,4,5,6,7), meaning no cycle exists.

<answer>True</answer>
