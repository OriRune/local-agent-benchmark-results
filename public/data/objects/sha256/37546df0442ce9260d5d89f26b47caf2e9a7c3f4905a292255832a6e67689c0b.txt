I've created a `README.md` file for the project that lists all CLI command line options with their help text. The README includes:

- **Usage section** showing how to run the CLI
- **Options table** with all three CLI options:
  - `URL` (positional): "what to download"
  - `-o` / `--output`: "file to write (default: stdout)"
  - `-q` / `--quiet`: "no progress output"
- **Examples** demonstrating common use cases
- **Configuration section** listing the default settings from `app/config.py`
- **License** section

The options are extracted directly from the `argparse` configuration in `app/cli.py`.
