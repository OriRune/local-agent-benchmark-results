Based on the code in `app/net.py` and `app/config.py`:

The `fetch` function loops with `for attempt in range(MAX_RETRIES)`, where `MAX_RETRIES = 3`. This means it tries attempts 0, 1, and 2.

Each failed attempt (OSError) causes a sleep of `2 ** attempt` seconds:
- Attempt 0 fails: sleep 2⁰ = 1 second
- Attempt 1 fails: sleep 2¹ = 2 seconds
- Attempt 2 fails: sleep 2² = 4 seconds

**Total sleep time if every attempt fails: 1 + 2 + 4 = 7 seconds**
