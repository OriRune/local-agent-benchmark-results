The fix has been applied. The issue was that `"KB"` was set to `1000` in the `UNITS` dictionary, but the test expects 1024-based units (as stated in the docstring). I changed `"KB": 1000` to `"KB": 1024`.

- **Problem:** The `parse_size` function used 1000 for KB instead of 1024, causing `parse_size("1.5 KB")` to return 1500 instead of the expected 1536.
- **Fix:** Changed `UNITS` dictionary entry for "KB" from 1000 to 1024 in `app/units.py`.
