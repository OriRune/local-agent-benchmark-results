The loop runs `for attempt in range(MAX_RETRIES)` with `MAX_RETRIES = 3`, so `attempt` takes values 0, 1, 2. On each failed attempt it sleeps `2 ** attempt` seconds:

- attempt 0 → 2⁰ = 1s
- attempt 1 → 2¹ = 2s
- attempt 2 → 2² = 4s

Total sleep = 1 + 2 + 4 = **7 seconds**.

(The `TIMEOUT_S = 20` timeout is separate — it's the per-attempt wait, not the sleep between attempts — and it only applies if attempts actually fail, which the question assumes.)
