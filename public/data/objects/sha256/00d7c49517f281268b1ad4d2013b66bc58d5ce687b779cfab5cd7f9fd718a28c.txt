1. CPU usage percentage (from `/proc/stat`)

3. Total RAM amount
4. CPU model information (from `/proc/cpuinfo`)

To use this script, you can make it executable and run it:

```bash
chmod +x system_info.sh
./system_info.sh
```

```bash
bash system_info.sh
```
