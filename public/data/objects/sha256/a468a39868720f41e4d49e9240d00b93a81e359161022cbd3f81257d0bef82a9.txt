## Setting Up the Problem

Let me define the four item types:
- Diamond ring (R): 195 owners
- Golf clubs (G): 367 owners  
- Garden spade (S): 562 owners
- Candy hearts (C): 900 owners (everyone owns these)

**Total count of items:**
$$195 + 367 + 562 + 900 = 2024$$

## Using Counting by Number of Items

Let $a_k$ = number of residents owning **exactly** $k$ things.

**Equation 1 — Total residents:**
$$a_1 + a_2 + a_3 + a_4 = 900$$

**Equation 2 — Sum of individual counts** (each person counted once per item they own):
$$a_1 + 2a_2 + 3a_3 + 4a_4 = 2024$$

## Solving

Subtract Equation 1 from Equation 2:
$$(a_1 + 2a_2 + 3a_3 + 4a_4) - (a_1 + a_2 + a_3 + a_4) = 2024 - 900$$

$$a_2 + 2a_3 + 3a_4 = 1124$$

Now substitute the given values $a_2 = 437$ and $a_3 = 234$:
$$437 + 2(234) + 3a_4 = 1124$$
$$437 + 468 + 3a_4 = 1124$$
$$905 + 3a_4 = 1124$$
$$3a_4 = 219$$
$$a_4 = 73$$

## Answer

The number of residents who own all four things is **073**.
