
Here is the script you requested:

```bash
#!/bin/bash
# Simple script to display RAM and CPU usage

echo "=== System Information ===\n"

# RAM usage
free -h | tail -n 2

echo -e "\n=== CPU Usage ===\n"
# Get a snapshot of CPU usage (percentage)
top -bn1 | grep "Cpu(s)" | awk '{print $2, $3, $4, $5, $6}'
```

Save this as `ram_cpu_info.sh` and run it with `./ram_cpu_info.sh` to see the current RAM and CPU usage.
