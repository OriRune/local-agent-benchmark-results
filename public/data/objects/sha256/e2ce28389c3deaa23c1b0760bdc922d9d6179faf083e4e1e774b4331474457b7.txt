I have created a `README.md` file for the project, which includes a usage section and a table listing all the command-line options and their corresponding help text as defined in `app/cli.py`.

```markdown
# tinydl

A tiny downloader CLI.

## Usage

```bash
tinydl [options] <url>
```

## Command Line Options

| Option | Help Text |
| --- | --- |
| `url` | what to download |
| `-o`, `--output` | file to write (default: stdout) |
| `-q`, `--quiet` | no progress output |
```
