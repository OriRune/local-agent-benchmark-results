I've created a README.md file that documents all command-line options for the tinydl CLI tool. The README includes:

- A brief description of the project
- Usage syntax
- A table listing every command-line option with its help text:
  - `url` - what to download
  - `-o` / `--output` - file to write (default: stdout)
  - `-q` / `--quiet` - no progress output
- Example usage commands demonstrating various combinations of options
