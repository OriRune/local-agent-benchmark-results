The `fetch` function in `app/net.py` uses a loop that runs for `MAX_RETRIES` attempts. If an attempt fails with an `OSError`, it sleeps for `2 ** attempt` seconds.

According to `app/config.py`, `MAX_RETRIES` is set to `3`.

If every attempt fails, the sleep durations will be:
- Attempt 0: `2 ** 0 = 1` second
- Attempt 1: `2 ** 1 = 2` seconds
- Attempt 2: `2 ** 2 = 4` seconds

Total sleep time = $1 + 2 + 4 = 7$ seconds.
