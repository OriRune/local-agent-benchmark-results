The `fetch` function in `app/net.py` has a loop that sleeps `2 ** attempt` seconds on each failed attempt. With `MAX_RETRIES = 3`, the loop runs for attempts `0`, `1`, and `2`.

The sleep durations are:
- Attempt 0: `2 ** 0 = 1` second
- Attempt 1: `2 ** 1 = 2` seconds
- Attempt 2: `2 ** 2 = 4` seconds

Total sleep time: `1 + 2 + 4 = 7` seconds.

So the function spends **7 seconds** sleeping in total before giving up (raising a `RuntimeError`).
