Done. I added `format_bytes(n)` to `app/util.py` and removed the TODO comment.

The new function scales a byte count down by 1024 through units (B, KB, MB, GB, TB, PB) and returns a string like `'1.5 KB'`:
- Values under 1024 return whole bytes, e.g. `'500 B'`
- Larger values return one decimal place, e.g. `'1.5 KB'`, `'1.0 MB'`

Manual trace confirms the logic: `format_bytes(1536)` → `1536 / 1024 = 1.5` → `'1.5 KB'`.
