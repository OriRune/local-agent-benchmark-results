So the loop runs 3 times (attempt = 0, 1, 2).

If every attempt fails, it sleeps:
- Attempt 0: `2^0 = 1` second
- Attempt 1: `2^1 = 2` seconds
- Attempt 2: `2^2 = 4` seconds

Total sleep time = 1 + 2 + 4 = **7 seconds**

The function gives up after the loop completes (after attempt 2 fails), raising a RuntimeError. The total sleep time before giving up is 7 seconds.
