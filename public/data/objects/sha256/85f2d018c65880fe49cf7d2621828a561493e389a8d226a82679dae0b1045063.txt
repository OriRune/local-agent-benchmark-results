# tinydl

A simple CLI tool to download content from a URL.

## Usage

```bash
tinydl [URL] [OPTIONS]
```

## Options

| Option | Description |
| --- | --- |
| `url` | what to download |
| `-o`, `--output` | file to write (default: stdout) |
| `-q`, `--quiet` | no progress output |
```
