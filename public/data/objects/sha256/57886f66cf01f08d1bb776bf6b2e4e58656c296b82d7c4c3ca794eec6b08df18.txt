The test failed because of a bug in `app/units.py`: the `UNITS` table defined `"KB": 1000`, but the module's own docstring says sizes use 1024-based units (1 KB = 1024 bytes). So `parse_size("1.5 KB")` returned `1500` instead of the expected `1536`.

I fixed the code by changing `"KB": 1000` to `"KB": 1024` in `app/units.py`. Now all three assertions pass:
- `parse_size("512 B")` → 512
- `parse_size("1.5 KB")` → 1536
- `parse_size("2 MB")` → 2 × 1024 × 1024

The test itself was left untouched.
