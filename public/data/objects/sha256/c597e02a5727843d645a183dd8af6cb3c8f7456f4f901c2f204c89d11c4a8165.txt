Working it out from `app/net.py`:

```python
def fetch(url, get):
    for attempt in range(MAX_RETRIES):   # MAX_RETRIES = 3 → attempts 0, 1, 2
        try:
            return get(url, timeout=TIMEOUT_S)
        except OSError:
            time.sleep(2 ** attempt)     # sleep after each failed attempt
    raise RuntimeError(f"giving up on {url}")
```

With `MAX_RETRIES = 3`, if every attempt fails it sleeps once per attempt:

- attempt 0 → `2**0` = 1 s
- attempt 1 → `2**1` = 2 s
- attempt 2 → `2**2` = 4 s

Total: 1 + 2 + 4 = **7 seconds** before it raises the "giving up" error.

(Note: `TIMEOUT_S = 20` is the per-call network timeout, not part of the sleep total — the question asks only about `time.sleep`.)
