From the code:

- `MAX_RETRIES = 3`, so the loop iterates with `attempt = 0, 1, 2`.
- On each failure, it sleeps for `2 ** attempt` seconds:
  - Attempt 0: `2⁰ = 1` second
  - Attempt 1: `2¹ = 2` seconds
  - Attempt 2: `2² = 4` seconds

**Total sleep time: 1 + 2 + 4 = 7 seconds** before it gives up.
