The relevant code is in `app/net.py`, using `MAX_RETRIES` from `app/config.py`.

**How it works:**
- `MAX_RETRIES = 3`, so the loop runs with `attempt` = 0, 1, 2.
- On each failed attempt it sleeps `2 ** attempt` seconds (exponential backoff).

**Sleep per attempt:**
| attempt | `2 ** attempt` | seconds |
|---------|----------------|---------|
| 0 | 2⁰ | 1 |
| 1 | 2¹ | 2 |
| 2 | 2² | 4 |

**Total:** 1 + 2 + 4 = **7 seconds** before the `RuntimeError` and it gives up.
