The Python script displays:
1. **RAM Usage** - Shows total, used, and available memory using `free -h`
2. **CPU Usage** - Shows user, system, and idle CPU percentages using `top`
3. **CPU Details** - Shows the number of CPU cores
4. **Memory Details** - Shows detailed memory info from `/proc/meminfo`
