Done. I created `system_usage.py` in the project folder — a self-contained Python script (no third-party packages) that reads `/proc/meminfo` and `/proc/stat` directly.

**What it shows:**
- **RAM** — used / total in MiB, percentage used, and available memory
- **CPU** — usage percentage measured over a 1-second interval

**Example output:**
```
=== System usage ===
RAM:  15306.1 MiB used / 128738.8 MiB total (11.9% used, 113432.7 MiB available)
CPU:  7.8% used (measured over 1 second)
```

Run it with `python3 system_usage.py`. It's verified to run correctly and consistently on this machine.
