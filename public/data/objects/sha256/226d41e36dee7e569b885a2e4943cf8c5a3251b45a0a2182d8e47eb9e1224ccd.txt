The fix is complete. The bug was that `UNITS["KB"]` was set to 1000 instead of 1024, which contradicted the docstring ("Sizes use 1024-based units: 1 KB = 1024 bytes") and caused the test `parse_size("1.5 KB") == 1536` to fail (it would have returned 1500).

Changed `UNITS = {"B": 1, "KB": 1000, ...}` to `UNITS = {"B": 1, "KB": 1024, ...}`.

Now the test expectations are met:
- `parse_size("512 B")` = 512 ✓
- `parse_size("1.5 KB")` = 1536 ✓  
- `parse_size("2 MB")` = 2 * 1024 * 1024 ✓
