Looking at the code in `app/net.py`:

```python
def fetch(url, get):
    # TODO: log each failed attempt
    for attempt in range(MAX_RETRIES):
        try:
            return get(url, timeout=TIMEOUT_S)
        except OSError:
            time.sleep(2 ** attempt)
    raise RuntimeError(f"giving up on {url}")
```

And the configuration in `app/config.py`:

```python
MAX_RETRIES = 3
```

The loop runs for `MAX_RETRIES` iterations (3 attempts: 0, 1, 2). Each failed attempt sleeps for `2 ** attempt` seconds:

- **Attempt 0**: sleeps for `2^0 = 1` second
- **Attempt 1**: sleeps for `2^1 = 2` seconds  
- **Attempt 2**: sleeps for `2^2 = 4` seconds

**Total sleep time = 1 + 2 + 4 = 7 seconds**
