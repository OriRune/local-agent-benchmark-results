Working it out from the code:

**The retry loop** (`app/net.py`):
```python
for attempt in range(MAX_RETRIES):   # MAX_RETRIES = 3 → attempt = 0, 1, 2
    try:
        return get(url, timeout=TIMEOUT_S)
    except OSError:
        time.sleep(2 ** attempt)
```

If every attempt fails, each iteration sleeps `2 ** attempt`:

| Attempt | Sleep |
|---------|-------|
| 0 | 2⁰ = 1 s |
| 1 | 2¹ = 2 s |
| 2 | 2² = 4 s |

After attempt 2 fails, `range(3)` is exhausted and it raises `RuntimeError("giving up")`.

**Total sleep = 1 + 2 + 4 = 7 seconds.**
