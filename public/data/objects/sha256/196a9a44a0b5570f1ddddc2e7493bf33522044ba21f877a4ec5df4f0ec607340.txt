The fix is in place. The root cause was that `UNITS["KB"]` was set to `1000` instead of `1024`. The docstring and the test both use 1024-based units (1 KB = 1024 bytes), but the constant was wrong.

The test `test_parse_size` checks `parse_size("1.5 KB") == 1536`. With the old value of `1000`, `1.5 * 1000 = 1500`, which fails. Changing `"KB": 1000` to `"KB": 1024` makes `1.5 * 1024 = 1536`, which passes.
