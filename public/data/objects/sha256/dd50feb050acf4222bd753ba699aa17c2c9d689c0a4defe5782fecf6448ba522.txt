I have added the `format_bytes(n)` function to `app/util.py` and removed the TODO comment. The function converts a byte count into a human-readable string (e.g., '1.5 KB').

```python
def format_bytes(n):
    for unit in ['B', 'KB', 'MB', 'GB', 'TB']:
        if n < 1024:
            return f"{n:.1f} {unit}"
        n /= 1024
    return f"{n:.1f} PB"
```
