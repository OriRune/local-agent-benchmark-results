Looking at the code in `app/net.py`:

```python
def fetch(url, get):
    for attempt in range(MAX_RETRIES):
        try:
            return get(url, timeout=TIMEOUT_S)
        except OSError:
            time.sleep(2 ** attempt)
    raise RuntimeError(f"giving up on {url}")
```

And from `app/config.py`: `MAX_RETRIES = 3`

If every attempt fails, the loop runs for `attempt = 0, 1, 2` (since `range(3)`), and each time it sleeps `2 ** attempt` seconds:
- attempt=0: `2 ** 0 = 1` second
- attempt=1: `2 ** 1 = 2` seconds  
- attempt=2: `2 ** 2 = 4` seconds

**Total sleep time = 1 + 2 + 4 = 7 seconds**

After all 3 attempts fail, it raises `RuntimeError(f"giving up on {url}")` and exits.
