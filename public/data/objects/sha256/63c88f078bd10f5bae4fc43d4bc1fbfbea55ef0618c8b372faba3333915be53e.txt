Done. I added `format_bytes(n)` to `app/util.py` and removed the TODO comment.

The function iterates through size units (B, KB, MB, GB, TB, PB), dividing by 1024 until the value is under 1024, then formats it. For example, `format_bytes(1536)` returns `'1.5 KB'`, and whole-byte values like `format_bytes(512)` return `'512 B'`.
