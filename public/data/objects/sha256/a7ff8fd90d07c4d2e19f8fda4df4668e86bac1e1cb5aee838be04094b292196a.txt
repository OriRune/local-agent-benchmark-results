I found the relevant code in `app/net.py`:

```python
def fetch(url, get):
    for attempt in range(MAX_RETRIES):
        try:
            return get(url, timeout=TIMEOUT_S)
        except OSError:
            time.sleep(2 ** attempt)
    raise RuntimeError(f"giving up on {url}")
```

and `app/config.py`:

```python
MAX_RETRIES = 3
TIMEOUT_S = 20
```

The sleep times are:
- attempt 0: 2⁰ = 1 s
- attempt 1: 2¹ = 2 s
- attempt 2: 2² = 4 s

Total sleep before giving up: **1 + 2 + 4 = 7 seconds**.
