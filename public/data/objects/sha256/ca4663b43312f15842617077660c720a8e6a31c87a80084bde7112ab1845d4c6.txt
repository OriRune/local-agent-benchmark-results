The test can't be run in the sandbox, but the fix is straightforward. The bug was in `app/units.py`: the `"KB"` unit was mapped to `1000` (decimal/SI bytes) instead of `1024` (binary bytes), which the docstring and the test both expect. Changing it from `1000` to `1024` resolves the failure — `parse_size("1.5 KB")` now correctly returns `1536` instead of `1500`.
