I created `README.md`. It documents the three command line options of the `tinydl` CLI (from `app/cli.py`), each with its help text:

- **`url`** — what to download (positional argument)
- **`-o`, `--output`** — file to write (default: stdout)
- **`-q`, `--quiet`** — no progress output

I also added a short usage section and two examples. Note that I couldn't run the CLI in the sandbox to capture the live `--help` output, so the help text was taken directly from the `argparse` definitions in `app/cli.py`.
