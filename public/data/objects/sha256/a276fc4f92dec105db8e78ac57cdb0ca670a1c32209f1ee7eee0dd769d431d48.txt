Looking at the code in `app/net.py`, the `fetch` function has a retry loop that sleeps between attempts:

```python
for attempt in range(MAX_RETRIES):
    try:
        return get(url, timeout=TIMEOUT_S)
    except OSError:
        time.sleep(2 ** attempt)
```

From `app/config.py`, `MAX_RETRIES = 3`.

So the loop runs for `attempt = 0, 1, 2`. If every attempt fails, the sleep times are:
- attempt 0: 2^0 = 1 second
- attempt 1: 2^1 = 2 seconds
- attempt 2: 2^2 = 4 seconds

**Total sleep time: 1 + 2 + 4 = 7 seconds**
