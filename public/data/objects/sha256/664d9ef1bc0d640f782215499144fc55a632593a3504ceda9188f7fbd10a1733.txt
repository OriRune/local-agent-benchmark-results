Done. I added `format_bytes(n)` to `app/util.py` and removed the TODO comment.

The function returns human-readable sizes using binary units (1024-based), for example:
- `512` → `512 B`
- `1536` → `1.5 KB`
- `1024**2` → `1024 KB`
- `2*1024**3` → `2048 KB`
- `5*1024**4` → `5 TB`

It iterates through the unit steps and returns the first one whose size is greater than `n` (formatted with one decimal), or the exact value for bytes.
