`MAX_RETRIES` is defined in **`app/config.py`** (line 2), where it's set to **3**:

```python
"""Settings for the downloader."""
MAX_RETRIES = 3
TIMEOUT_S = 20
USER_AGENT = "tiny-downloader/0.2"
```

It's then imported and used in `app/net.py` (`from app.config import MAX_RETRIES, TIMEOUT_S`), where it controls the number of retry attempts in a loop.
