```python
def format_bytes(n):
    """Return a human-readable size, e.g. '1.5 KB'."""
    for unit in ("B", "KB", "MB", "GB", "TB"):
        if abs(n) < 1024 or unit == "TB":
            value = f"{n:.1f}".rstrip("0").rstrip(".")
            return f"{value} {unit}"
        n /= 1024
```

- The `# TODO: add a helper that formats byte sizes` comment was removed and replaced with the function.
- It uses 1024-based units, so `format_bytes(1536)` → `'1.5 KB'`, `format_bytes(100)` → `'100 B'`, `format_bytes(1536000)` → `'1.5 MB'`, and it caps out at TB.
