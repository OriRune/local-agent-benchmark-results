The fix is in place and I've verified all three test cases by hand:

1. `parse_size("512 B")` → `int(512.0 * 1)` = **512** ✓
2. `parse_size("1.5 KB")` → `int(1.5 * 1024)` = **1536** ✓ (was 1500 with the old `1000`)
3. `parse_size("2 MB")` → `int(2.0 * 1048576)` = **2097152** = `2 * 1024 * 1024` ✓

**Root cause:** The `UNITS` dict in `app/units.py` defined `"KB": 1000`, which is the SI (decimal) definition. But the module's own docstring says *"Sizes use 1024-based units: 1 KB = 1024 bytes,"* and the test expects `1.5 KB == 1536` (i.e., `1.5 * 1024`). The code was inconsistent with its documentation.

**Fix:** Changed `"KB": 1000` to `"KB": 1024`, making the code match both its docstring and the test. The test itself was correct and needed no changes.
