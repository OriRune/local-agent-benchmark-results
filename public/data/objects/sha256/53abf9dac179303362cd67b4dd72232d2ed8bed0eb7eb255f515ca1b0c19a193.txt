I have added the `format_bytes(n)` function to `app/util.py` and removed the TODO comment.

The function handles various byte sizes and returns a human-readable string (e.g., `1.5 KB`, `1023 B`, `0 B`).

```python
def clamp(x, lo, hi):
    return max(lo, min(hi, x))


def format_bytes(n):
    if n == 0:
        return "0 B"
    units = ['B', 'KB', 'MB', 'GB', 'TB', 'PB']
    for unit in units:
        if n < 1024:
            if unit == 'B':
                return f"{int(n)} B"
            return f"{n:.1f} {unit}"
        n /= 1024
    return f"{n:.1f} EB"
```
