The fix is complete. Here's a summary:

## Root cause
In `app/units.py`, the `UNITS` dictionary mapped `"KB"` to `1000` (a decimal/SI value), which contradicted the module's own docstring — *"Sizes use 1024-based units: 1 KB = 1024 bytes"* — and caused the test to fail:
- `parse_size("1.5 KB")` returned `1.5 × 1000 = 1500`, but the test expected `1536` (`1.5 × 1024`).

The other two cases (`"512 B"` → 512 and `"2 MB"` → 2097152) were already correct.

## Fix
Changed `"KB": 1000` to `"KB": 1024` in `app/units.py`, making the constant consistent with the documented 1024-based convention. All three assertions now pass:
- `parse_size("512 B")` → `512` ✓
- `parse_size("1.5 KB")` → `1536` ✓
- `parse_size("2 MB")` → `2097152` ✓
