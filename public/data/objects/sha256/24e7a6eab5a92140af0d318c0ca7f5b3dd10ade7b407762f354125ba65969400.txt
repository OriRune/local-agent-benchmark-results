The `fetch` function in `app/net.py` uses `MAX_RETRIES = 3` (from `app/config.py`). The loop runs for `attempt` in `range(3)`, so attempts 0, 1, and 2. On each failure, it sleeps `2 ** attempt` seconds:

- Attempt 0: `2^0 = 1` second
- Attempt 1: `2^1 = 2` seconds
- Attempt 2: `2^2 = 4` seconds

**Total sleep = 1 + 2 + 4 = 7 seconds** before it raises `RuntimeError` and gives up.
